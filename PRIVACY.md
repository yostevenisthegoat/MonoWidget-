# WidgetLite Privacy Policy

**Last updated:** 2026

WidgetLite is built to respect your privacy completely.

## Data Collection

- **No Personal Accounts:** WidgetLite does not require or support account creation.
- **No Analytics or Ads:** WidgetLite contains zero advertising SDKs, zero behavioral trackers, and zero analytics frameworks.
- **Local-First Storage:** All widget styles, notes, to-do lists, habits, reminders, and custom photos are stored strictly on your device using Android Room, DataStore, and private internal app storage.

## Permissions & Network Usage

- **Internet (`INTERNET`, `ACCESS_NETWORK_STATE`):** Used only when you search for a city or refresh Weather widgets via the free, privacy-respecting Open-Meteo API, or when you check network status. You can disable Weather network requests anytime in **Settings -> Privacy**.
- **Wi-Fi State (`ACCESS_WIFI_STATE`):** Used locally to display link speed and signal strength on the Wi-Fi widget. WidgetLite does not request location permission to read your SSID.
- **Photo Picker:** Uses Android's zero-permission Photo Picker (`PickVisualMedia`) so WidgetLite only accesses the exact image you select.
- **Notifications (`POST_NOTIFICATIONS`, optional):** Requested only if you explicitly enable alert notifications for a Daily Reminder widget.
